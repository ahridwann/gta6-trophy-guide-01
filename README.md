Leonida Legends is the complete offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every official name, description and grade as PlayStation publishes them, a guide in our own words with its sources cited beside each trophy, a six-stage roadmap to the platinum, every missable trophy flagged, and a checklist that saves your progress in the browser, with filters by kind, a spoiler-free mode that hides story trophies until they are earned, and export/import of your progress. It is static files only and works with the network off.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. To build the entry output instead: `MAKEFUN_OUTPUT_DIR=out node main.ts`.
